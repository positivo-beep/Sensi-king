Para subirlo con GitHub Desktop:

2. Copia el CONTENIDO extraido dentro de la carpeta local de tu repositorio Sensi-king.
3. Acepta reemplazar archivos existentes, pero no borres la carpeta .git.
4. Abre GitHub Desktop, comprueba los cambios, haz Commit y Push origin.
5. Revisa el resultado en Actions. Si compila, descarga la IPA sin firmar.
